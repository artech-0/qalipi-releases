# Quire

Quire is an Android ebook and comic reader in early development. EPUB reading is currently implemented; additional formats and features are planned.

## Downloads

No app releases have been published yet. Downloadable APKs will be attached to this repository's GitHub Releases, with release notes and SHA-256 checksums for each version.

Requires Android 8.0 (API 26) or newer.

## Release history

See [CHANGELOG.md](CHANGELOG.md) for version history. This repository contains app distribution documentation; the source code is maintained separately.
